# Практическая 7. Загрузка изображения в потоках Network и Disk

Модуль 2. Мазенин Артем Андреевич, ИКБО-63-23.

## Задание

Предусмотреть ввод ссылки и кнопку загрузки. Нажатие должно запускать поток Network для получения изображения и поток Disk для сохранения во внутренней памяти.

## Реализация

ImageDownloader создает два однопоточных executor с именами Network и Disk. Нажатие отправляет сетевую задачу через submit, а файловую - через execute. Disk ожидает результат с ограничением времени, проверяет сигнатуру PNG/JPEG и записывает байты в filesDir/images.

ImagePolicy проверяет схему HTTP(S), наличие хоста и сигнатуру файла. Сетевой код проверяет HTTP-статус, использует тайм-ауты и ограничивает размер ответа 10 МБ. Соединение закрывается в finally. При завершении ViewModel executors останавливаются.

Экран содержит ссылку, кнопку, статус, предпросмотр и историю. Состояние передается через LiveData. На время операции повторная загрузка блокируется, после завершения показываются имя файла, размер и фактические имена потоков.

## Запуск

Откройте **корень репозитория** в Android Studio, выберите модуль `pr07` и устройство API 26+. Эта папка использует общие настройки Gradle из корня.

Сборка из корня:

```powershell
.\gradlew.bat :pr07:assembleDebug
```

## Демонстрация

1. Загрузить https://httpbin.org/image/png. Ожидается: Изображение получено и сохранено.
2. Посмотреть статус результата. Ожидается: Network → Disk.
3. Проверить историю. Ожидается: Сохраненный файл виден в списке.
